# WirelessBatteryMoniter 页面设计方案

更新日期：2026-11-20。设计对象为 Windows 无线设备电量工具，覆盖主窗口、设置窗口和异常详情。本方案采用 frontend-design 的设计方法，字体按本机 Codex 的系统字体栈修订；当前为设计规格，尚未修改应用界面。

## 设计定位

面向同时使用无线鼠标、键盘、耳机的 Windows 用户。打开窗口即可了解设备还有多少电、是否需要处理，以及读数是否可靠。

延续深色界面，以整齐的设备列表和横向电量刻度形成识别感。视觉重点放在设备本身，减少大面积统计卡片。

## 主页面布局

## 配色

| 角色 | 色值 | 用途 |
|---|---|---|
| 石墨背景 | `#161B22` | 窗口背景 |
| 面板灰 | `#222A35` | 设置分区、交互区域 |
| 雾白 | `#EDF2F7` | 设备名称、主要读数 |
| 冷灰 | `#AAB7C7` | 连接方式、时间、说明 |
| 仪表蓝 | `#68B8F7` | 正常电量、按钮、焦点 |
| 琥珀橙 | `#F0B45A` | 低电量、读取异常 |

正常状态使用蓝色，异常状态配合图标和明确文字，避免仅依赖颜色传达信息。

## 字体与排版

中英文统一沿用 Codex 的系统无衬线字体栈。取消原方案中单独为中文指定字体、再为英文指定另一套字体的规则。常规与加粗使用同一字体栈，仅改变字重。

| 内容 | 字体规则 | 常规样式 | 加粗样式 |
|---|---|---|---|
| 英文和数字 | 本机 Windows 默认栈中的 Segoe UI | Regular，400 | Bold，700 |
| 中文 | 使用与 Codex 相同的系统中文回退机制 | 回退字体的常规字形，400 | 回退字体的加粗字形，700 |

网页原型采用以下字体规格：

```css
:root {
  --font-ui: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
  --font-regular: 400;
  --font-bold: 700;
}

body, button, input, select, textarea {
  font-family: var(--font-ui);
  font-weight: var(--font-regular);
}

h1, h2, h3, strong, .device-name, .battery-value {
  font-weight: var(--font-bold);
}
```

| 元素 | 逻辑字号 | 字重 | 行高 |
|---|---|---|---|
| 窗口内标题 | 20px | 700 | 28px |
| 分区标题、设备名称 | 16px | 700 | 24px |
| 电量数字 | 28px | 700 | 36px |
| 按钮、正文、设置项 | 14px | 400 | 22px |
| 状态、时间、辅助信息 | 13px | 400 | 20px |

字距保持正常，不拉宽中文或英文标签。中英文混排共享基线；数字列保持右对齐。所有字号随系统 DPI 缩放，避免先绘制文字再拉伸位图。

### 本机字体核对依据与实现边界

核对对象为本机 Codex 安装包 `OpenAI.Codex_26.908.4834.0_x64__2p2nqsd0c76g0` 的 `resources/app.asar`，主样式文件为 `webview/assets/app-dddf03d14541.css`。

- 默认字体定义为 `--font-sans-default: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`。
- 界面使用 `--font-ui-family`（未覆盖时回落到默认栈），正文使用 `--codex-content-font-family`（未覆盖时回落到界面字体）。
- 常规字重定义为 400，加粗定义为 700。
- 安装包虽包含 OpenAI Sans，但其使用独立变量，不能据此将其认定为整个 Codex 界面的默认字体。
- 本机 Windows 的 Segoe UI 字体链接配置包含 Microsoft YaHei UI。中文可能仍由该字体显示；此处未逐字验证正在显示的 Codex 页面的实际字体，也未确认运行时是否覆盖默认字体。

本方案以已核实的 Codex 默认字体栈为目标。原生 WinForms 与 Codex 的 Chromium 渲染可能存在差异，不能仅凭同名字体保证完全一致。实现时需用相同中文、英文、数字及 400/700 字重进行并排视觉核对；若仍有差异，核对实际回退字体、字号、DPI 和文本渲染方式后再调整。

## 读数与状态表达

| 情况 | 界面表达 |
|---|---|
| 正常读取 | 显示百分比、连接方式和读取时间 |
| 电量偏低 | 橙色电量条，并显示“电量偏低” |
| 使用缓存 | 显示“上次读数 70%”及原读取时间，电量条降低强调程度 |
| 连接待确认 | 明确显示“连接待确认”，避免误报为已连接 |
| 未获取电量 | 显示“—”和“暂未获取电量”，不显示 0% |
| 部分读取失败 | 保留成功设备结果，展示“部分设备读取失败”和“查看详情” |
| 未发现设备 | 提示“尚未发现支持读取电量的设备”，提供“重新扫描” |

扫描完成时间与设备读数时间分别呈现，避免让旧缓存看起来像刚获取的数据。

## 设置页面

采用单列布局，按用途划分为三个区域：

- **设备监控**：刷新间隔、显示未连接设备。
- **低电量提醒**：启用提醒、提醒阈值、提示音、发送测试提醒。
- **启动与后台**：开机自动启动、启动时最小化。

每行左侧是名称和简短说明，右侧是开关或数值控件。底部固定“取消”和“保存设置”。关闭提醒时，其相关选项禁用并说明原因。

## 交互细节

点击“立即刷新”后显示“正在读取…”，扫描期间禁止重复触发。设备数值更新时原位替换，仅用短暂颜色变化提示更新，不做连续闪烁或循环动画；遵循系统减少动画偏好。

异常详情支持点击打开和复制。长设备名称允许换行，并能查看完整名称。关闭主窗口继续后台运行，“退出程序”保留在明确的菜单入口中。

托盘继续使用现有纯文字悬停提示，让后台查看保持轻量。

## 设计取舍与验收

将大号最低电量统计卡片收敛为一行摘要，把空间留给设备名称、电量和读数时间。界面的特色来自统一的电量刻度和清楚的数据状态。

落地时重点检查：

- 1 台、3 台及较多设备时，信息层级是否清楚。
- 长名称、缓存、断开和读取异常是否完整显示。
- Windows 100%、150%、200% 缩放下是否遮挡或截断。
- 中英文常规与加粗效果是否与本机 Codex 对照一致，是否出现缺字或意外字体替换。
- 键盘操作、焦点提示和文字对比度是否可用。

第一阶段覆盖主窗口、设置窗口和异常详情，后续再统一关于窗口与低电量提醒的样式。
