# WirelessBatteryMoniter 柔和卡片界面设计方案

本方案以用户提供的 FlClash 官网截图为视觉参考，将圆润卡片、同色系层次、胶囊控件和清楚的数据层级应用到无线设备电量工具。风格定位为具有 Material You 观感的轻量桌面应用，保留用户指定的 Codex 字体规则。

适用范围：主窗口、设置窗口、设备详情与异常提示。本文替代此前的横线分隔式桌面仪表方案，作为后续界面实现依据；当前交付为设计方案。

## 设计目标与参考边界

用户打开窗口后，应能快速找到需要充电的设备，并区分当前读数、缓存读数和未连接状态。界面既要有截图中的柔和感，也要适合只有一至三台设备的日常使用。

参考截图中值得继承的是大圆角容器、弱边框、色阶分层、醒目的数值、简洁图标和胶囊式操作。Google Play Store 是用户对整体观感的类比，不将本方案描述为其官方设计规范。以下尺寸和色值是为本项目制定的规格，并非对 FlClash 的精确取样。

保留一处有表现力的视觉重点：设备电量数字与其对应的圆头电量条。花瓣按钮、流量曲线、IP 信息和代理模式等参考软件专有元素不进入电量工具；不增加没有数据来源的续航预测、历史曲线或充电动画。

图中名称、数量、电量及时间为示例。正常情况下只显示一行概览，不使用大号总览卡片。只有一台设备时仍保持自然卡片高度，不将它拉伸填满窗口。

客户区宽度小于 800 时使用单列；达到 800 时设备区域可使用两列，每列至少 360 宽，按从左到右、从上到下排列。低电量设备在首次展示时优先，后续刷新不自动跳动排序；新设备追加，重开窗口时重新排序。名称最多两行，完整名称在详情及悬停提示中可见。窄窗口中时间移到独立行，卡片随内容增高。

## 颜色系统

默认使用浅色蓝主题，贴近参考图右侧手机界面的清爽感；同时定义深色蓝主题，方便日后提供主题切换。主题切换属于界面新增设置，首期可先实现浅色版。深浅主题保持相同结构和状态含义。

核心配色为以下六个角色，其余颜色仅用于明确状态或交互。

| 角色 | 浅色主题 | 深色主题 | 用途 |
|---|---|---|---|
| 窗口背景 | `#F2F3F7` | `#171A20` | 整体底色 |
| 卡片表面 | `#FFFFFF` | `#242932` | 设备与设置分组 |
| 次级表面 | `#E9EDF5` | `#303846` | 图标底座、未选中胶囊、电量轨道 |
| 主题色 | `#145CCD` | `#A9C7FF` | 主操作、正常电量、焦点 |
| 主要文字 | `#202630` | `#EEF2FA` | 标题、设备名称、电量 |
| 次要文字 | `#586275` | `#B4BDCC` | 连接方式、时间和说明 |

| 状态或交互 | 浅色主题 | 深色主题 |
|---|---|---|
| 主按钮文字 | `#FFFFFF` | `#142B50` |
| 选中或强调底色 | `#E4EDFF` | `#293D5F` |
| 警示文字及电量条 | `#8A4800` | `#FFD09A` |
| 警示容器背景 | `#FFF0DA` | `#49341E` |
| 严重低电量文字及电量条 | `#B3261E` | `#FFB4AB` |
| 严重低电量容器背景 | `#FCE8E6` | `#4D2927` |

普通卡片使用实色填充，不依赖描边或明显阴影区分。浅色主题允许非常轻的底部阴影，深色主题通过表面明暗区分。透明模糊不作为基础视觉要求。悬停在表面叠加约 4% 主题色，按下约 8%；禁用按钮使用次级表面与次要文字，并同时禁止交互。

颜色应用后需检查实际文字与背景对比度：普通文字至少 4.5:1，大号文字与必要控件边界至少 3:1；不得仅靠颜色区分状态。

## 组件规格

| 组件 | 规格 | 行为与内容 |
|---|---|---|
| 设备卡片 | 圆角 24，内边距 20，基础最小高度 144 | 名称左对齐、电量右对齐；内容变长时增高 |
| 图标底座 | 40 × 40，圆角 14，内部图标 22 | 统一线性鼠标、键盘、耳机图标；未知设备使用通用设备图标 |
| 电量数字 | 32px / 40px，加粗 700 | 百分号 16px，与数值基线对齐 |
| 电量条 | 高 8，圆头；与卡片内宽一致 | 已知值按 0–100% 表达；0% 无填充，不伪造最小值 |
| 状态标签 | 高至少 26，水平内边距 10，胶囊圆角 | 仅低电量、缓存、待确认等需关注状态使用强调底色 |
| 主按钮 | 高至少 40，水平内边距 18，胶囊圆角 | “立即刷新”“保存设置”；每个操作区域一个主按钮 |
| 次按钮 | 高至少 40，次级表面 | 设置、取消、复制详情；保留文字标签 |
| 开关 | 48 × 28，外部命中区域至少 44 × 44 | 选中时主题色轨道；支持键盘切换 |
| 设置分组 | 圆角 24，水平内边距 20 | 行高至少 64，说明文字换行后自动增高 |
| 异常摘要 | 圆角 16，内边距 16 | 简短说明加“查看详情”，位于概览下方 |

卡片可点击打开详情，但不在卡片内叠加多个不明确的点击区域。键盘焦点使用 2px 主题色外框，并预留 2px 间距；需验证焦点不被圆角裁剪。图标统一使用项目可分发的矢量或系统图标，不使用彩色 emoji 代替设备图标。

## 字体与排版

中英文统一沿用 Codex 的系统无衬线字体栈。取消原方案中单独为中文指定字体、再为英文指定另一套字体的规则。常规与加粗使用同一字体栈，仅改变字重。

| 内容 | 字体规则 | 常规样式 | 加粗样式 |
|---|---|---|---|
| 英文和数字 | 本机 Windows 默认栈中的 Segoe UI | Regular，400 | Bold，700 |
| 中文 | 使用与 Codex 相同的系统中文回退机制 | 回退字体的常规字形，400 | 回退字体的加粗字形，700 |

网页原型采用以下字体规格：

```css
:root {
  --font-ui: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
  --font-regular: 400;
  --font-bold: 700;
}

body, button, input, select, textarea {
  font-family: var(--font-ui);
  font-weight: var(--font-regular);
}

h1, h2, h3, strong, .device-name, .battery-value {
  font-weight: var(--font-bold);
}
```

| 元素 | 逻辑字号 | 字重 | 行高 |
|---|---|---|---|
| 窗口内标题 | 20px | 700 | 28px |
| 分区标题、设备名称 | 16px | 700 | 24px |
| 电量数字 | 32px | 700 | 40px |
| 按钮、正文、设置项 | 14px | 400 | 22px |
| 状态、时间、辅助信息 | 13px | 400 | 20px |

字距保持正常，不拉宽中文或英文标签。中英文混排共享基线；数字列保持右对齐。所有字号随系统 DPI 缩放，避免先绘制文字再拉伸位图。

### 本机字体核对依据与实现边界

核对对象为本机 Codex 安装包 `OpenAI.Codex_26.908.4834.0_x64__2p2nqsd0c76g0` 的 `resources/app.asar`，主样式文件为 `webview/assets/app-dddf03d14541.css`。

- 默认字体定义为 `--font-sans-default: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`。
- 界面使用 `--font-ui-family`（未覆盖时回落到默认栈），正文使用 `--codex-content-font-family`（未覆盖时回落到界面字体）。
- 常规字重定义为 400，加粗定义为 700。
- 安装包虽包含 OpenAI Sans，但其使用独立变量，不能据此将其认定为整个 Codex 界面的默认字体。
- 本机 Windows 的 Segoe UI 字体链接配置包含 Microsoft YaHei UI。中文可能仍由该字体显示；此处未逐字验证正在显示的 Codex 页面的实际字体，也未确认运行时是否覆盖默认字体。

本方案以已核实的 Codex 默认字体栈为目标。原生 WinForms 与 Codex 的 Chromium 渲染可能存在差异，不能仅凭同名字体保证完全一致。实现时需用相同中文、英文、数字及 400/700 字重进行并排视觉核对；若仍有差异，核对实际回退字体、字号、DPI 和文本渲染方式后再调整。

## 数据状态与文案

| 数据状态 | 设备卡片 | 概览与提醒规则 |
|---|---|---|
| 本轮成功读取 | 正常百分比、实色电量条、读取时间 | 计入已确认连接设备 |
| 达到提醒阈值 | 警示色条与“电量偏低”文字 | 沿用现有提醒阈值和通知逻辑 |
| 电量不高于 10% | 严重低电量色与“电量很低” | 视觉分级不改变现有通知触发规则 |
| 有缓存读数 | “上次读数 70%”，低强调电量条，原成功读取时间 | 不当作新鲜读数再次提醒 |
| 连接待确认 | “连接待确认”和“缓存读数” | 概览单独列出待确认数量，不冒充当前在线 |
| 已断开 | “未连接”，有历史值时标注“上次读数” | 根据“显示未连接设备”设置展示 |
| 无电量值 | 显示“—”“暂未获取电量”，仅保留轨道 | 不显示 0%，不推断电量 |
| 部分读取失败 | 成功设备继续更新，失败设备保留适用缓存 | 概览下显示“部分设备读取失败”和详情入口 |

状态组合允许同时存在，例如“连接待确认”和“缓存读数”。缓存或未连接设备不显示为新鲜的低电量告警；保留数值供参考，并优先说明读数有效性。清楚区分上轮扫描完成时间与每台设备的成功读取时间。

首次扫描时显示“正在查找设备…”，不先显示错误空态；扫描完成且没有设备时显示“尚未发现支持读取电量的设备”，辅助说明“请检查设备连接，然后重新扫描”，提供“重新扫描”。

## 设置与详情页面

设置窗口建议宽 480、初始高 680，使用三组圆角面板及可滚动内容区，底部固定“取消”“保存设置”：

- **设备监控**：刷新间隔（保留 5–120 秒范围）、显示未连接设备。
- **低电量提醒**：启用提醒、阈值（保留 5–95% 范围）、提示音、发送测试提醒。关闭提醒时禁用相关控件并保留值。
- **启动与后台**：开机自动启动、启动时最小化。

可选的后续“外观”分组提供浅色、深色、跟随系统三项。首次实施不因截图中的功能密度而增加导航侧栏或底部多标签导航。

设备详情以居中对话框显示完整名称、设备类型、连接方式、状态、已有的电量值与读取时间。异常详情展示可滚动的完整消息，提供“复制详情”和“关闭”。未提供的设备信息不生成占位假值。对话框打开后焦点进入内容，关闭后返回触发按钮；Esc 可关闭。

## 交互与动效

点击刷新后按钮变为“正在读取…”，禁止重复触发；刷新期间保留已有设备内容，完成后原位更新。失败时给出可操作说明，按钮恢复可用。

按钮与卡片的颜色反馈用 120–160ms；详情出现使用 160–200ms 的轻微淡入。减少动画模式下即时切换，不做数字滚动、电量条循环发光或卡片上下漂浮。读取时间持续可见，动画不替代状态说明。

关闭窗口继续托盘运行，真正退出使用明确的“退出程序”入口。托盘保持纯文字悬停提示。现有扫描、防抖、缓存、提醒和安装行为不因视觉改版改变。

## 实现映射

当前项目为 WinForms。沿用现有结构实现该风格，不因参考图使用 Flutter 而迁移框架。

| 文件 | 实施职责 |
|---|---|
| `src/WirelessBatteryMoniter/UI/Theme.cs` | 色彩、常规与加粗字体、间距和圆角统一定义 |
| `src/WirelessBatteryMoniter/UI/MainForm.cs` | 自适应窗口、概览、滚动区域、底部操作 |
| `src/WirelessBatteryMoniter/UI/DeviceCard.cs` | 柔和面板、图标、电量及状态布局 |
| `src/WirelessBatteryMoniter/UI/Controls.cs` | 胶囊按钮、开关、焦点与禁用反馈 |
| `src/WirelessBatteryMoniter/UI/SettingsForm.cs` | 分组设置、自动增高行与固定操作区 |

文本布局按实际测量结果排版。将逻辑尺寸统一映射到 DPI；32px 在 96 DPI 下为 24pt，避免将像素数直接当作 WinForms 字体磅值。对需要键盘操作的自绘组件提供可访问名称、角色、焦点和状态。实现时核对自绘文字与系统文字的渲染一致性。

## 验收与交付顺序

1. **静态视觉样稿**：展示浅色主窗口、深色主窗口、设置页及异常详情；使用相同三台示例设备比较层级、圆角、字体和状态。
2. **界面实现**：先完成浅色主窗口与基础控件，再完成设置、详情与可选深色主题。
3. **功能和视觉验收**：覆盖 0、1、3、10 台设备，超长中英文名称，同名设备，未知电量，0%/100%，低电量，缓存，待确认，断开和部分失败。
4. **缩放与操作验收**：在 100%、150%、200% DPI 和最小窗口下检查截断、滚动、焦点顺序及按钮可达性；比较 Codex 字体常规与加粗效果；检查主题对比度和减少动画模式。

通过标准：用户不打开详情也能判断设备电量及其可信状态；长名称不覆盖百分比；刷新不造成列表跳动；主操作可由键盘完成；视觉层级由色阶、留白和字号共同建立。
