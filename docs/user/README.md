# WirelessBatteryMoniter 1.4.1

Windows 10 1809+ / Windows 11 无线设备电量监控工具，需要 .NET Framework 4.8。

## 启动与安装

解压完整发布包，运行 `Start.cmd`，安装或升级到固定目录后启动。`Install.cmd` 只安装。日常从桌面快捷方式启动；实际运行文件始终是 `%LOCALAPPDATA%\Programs\WirelessBatteryMoniter\WirelessBatteryMoniterTray.exe`。不直接运行发布目录中的 EXE，避免产生不同路径的托盘记录。

升级前请从主窗口或托盘菜单退出旧程序。关闭主窗口只会隐藏窗口；主窗口底部或托盘菜单中的“退出”才会结束进程。再次启动会唤起已有实例。

## 使用

- 托盘图标显示设备数量及最低电量，可能位于任务栏的 `^` 隐藏区。
- 悬停第一行显示程序名和设备数量，之后按 `[连接方式] 类型: 名称 70%电量` 展示。纯文字提示框完整显示设备名称，宽度不足时换行。
- 设置可配置刷新间隔、低电量阈值、提示音、通知、未连接设备显示和开机启动。
- 主窗口使用浅蓝色圆角设备卡片；名称最多显示两行，点击卡片或按 Enter 查看完整详情。窄窗口单列，宽窗口可双列。刷新保留现有设备顺序，重开窗口重新排序。
- 待确认连接单独计数；缓存显示上次读数和原读取时间，未知电量显示“—”。
- 出现读取失败提示时，点击“查看详情”查看并复制完整原因。
- 正常慢查询显示“正在查询”，不会显示读取失败。底部时间表示最近一次通道查询实际结束的时间，等待下一轮期间不会随界面刷新改变；首次查询尚未结束时不显示完成时间。
- 设置分为设备监控、低电量提醒、启动与后台；关闭提醒时，相关选项暂不生效。
- 扫描失败时保留可用结果，旧读数标记缓存；2.4G/HID 未读到时显示“连接状态未知”，保留原电量和时间，多轮失败也不推断断开。未知设备不计入当前在线统计，恢复读数不会因此重复提醒；真实拔出也可能显示未知。
- 设置与日志优先存于 `%APPDATA%\WirelessBatteryMoniter`，不可写时回退至 LocalAppData 或程序旁 `UserData`。

## 支持与限制

支持 BLE 标准电池服务、Windows 经典蓝牙电量属性，以及部分罗技、ATK/VXE/CompX 2.4G 协议。本机实测两只 Logitech（PRO X 2、PRO X2 SUPERSTRIKE）与 XINMENG 3151:5045 接收器鼠标同时读取。其他型号需确认兼容性。缓存只保留本次运行；Windows 属性读数不保证是设备即时采样。35 秒是扫描取消请求时间，驱动清理可能更久。悬停采用纯文字提示框，不受原生托盘 127 字符限制。

本程序未签名，Windows 可能提示未知发布者。安装不会关闭系统安全检查。

## 诊断

- `--selftest`：逻辑自检。
- `--diagnose-scan`：等待蓝牙与 HID 的单次真实设备扫描完成后输出结果，不使用界面约 1.5 秒的短等待。通道约 35 秒超时后保留其他通道的结果并报告错误；诊断另有 40 秒总等待上限，原生驱动清理可能继续在后台进行。
- `--diagnose-tray`：离线托盘图像诊断，只导出预览，不注册图标；不验证 Explorer 实时注册。

结果写入 `%TEMP%` 下的 `WirelessBatteryMoniter-selftest.txt` 或 `WirelessBatteryMoniter-diagnostics`。逻辑测试通过不代表所有硬件与交互场景均已验证。

## 升级与历史记录

升级先暂存完整文件并逐一核对 SHA256，再替换固定安装目录；失败尝试回滚，旧目录保留在安装目录同级的 `.previous-WirelessBatteryMoniter-*` 中。不要从备份目录启动程序。不支持覆盖安装更低版本。安装相同文件可重复执行。

开发测试、历史发布包不再注册临时图标；固定安装路径可以避免由路径变化引起的持续新增。Windows 管理历史托盘缓存，旧开关不会因升级自动删除。安装器不清空共享缓存，也不重启 Explorer，避免影响其他软件的图标偏好。



## 电量来源与精度

电压曲线或粗略档位换算的电量显示为“约 50%”；设备详情列出读数来源与精度说明。设备直接上报百分比、蓝牙 GATT 与 Windows 电量属性分别标注，直接上报不等于实测精确；Windows 属性可能来自系统缓存。缓存保留原读数来源，恢复读取后采用新来源。提醒仍按数值阈值判断，并保留“约”字提示。

## 充电状态与提醒

已接入罗技 HID++ 0x1000/0x1004、0x1001 电压及 0x1F20 ADC 的充电状态字段。新鲜且已连接的读数确认正在充电或充电完成时，不发送低电量提醒，并重新布防；停止充电后仍低于阈值可提醒一次。未知充电状态沿用原低电量提醒规则，不根据百分比上涨或接入 USB 猜测充电。其他 HID 协议、罗技旧寄存器分支以及现有蓝牙查询暂未解析充电状态。缓存只保留历史充电状态，不用于重新布防或认定仍在充电。

## 电量历史

右键托盘 → **电量历史…**：按设备查看最近 24 小时或 7 天的趋势和读数明细。记录保存到设置目录的 `battery-history.json`，使用 UTC 存储、本地时间显示；程序重启后保留。隐藏设备仍会记录，可在历史窗口选择。

仅记录已连接、非缓存、非休眠的有效电量；演示数据不写入。电量、来源或充电状态改变时记录，持续有效且数值不变时每 10 分钟留一个点；重复的读取时间不重复写入。估算值显示“约”，来源和充电状态分别保存。图表不跨重启、连接未知或读数来源变化连线，超过 15 分钟的采样间隔也断开，不补造离线数据，不计算续航预测。

保留最近 7 天，最多 50000 个记录点，超限删除最旧记录；明细表最多显示最近 2000 条。写入在后台合并，正常退出时保存待写入数据；异常退出可能丢失最近约 30 秒尚未保存的数据。保存失败后保留内存记录并重试，托盘菜单和历史窗口显示错误。历史文件损坏时保留原文件并停止覆盖，可修复文件后点“刷新 / 重试”。

## 新增协议路径与验证范围

- Logitech HID++ `0x1001`：在已有电压估算基础上解析充电标志；缺少标志字节或遇到未识别状态时保留“未知”。
- Logitech HID++ `0x1F20` ADC：设备宣告支持该功能且返回有效电压时读取电量和充电状态；百分比仍属于电压估算，不显示为原生精确百分比。
- 原有 `0x1000`、`0x1004` 及 HID++ 1.0 电量读取保留。其他品牌、BLE 充电状态和耳机左右独立电量未因此获得新增支持。

字段与 [Solaar 的 HID++ 实现](https://github.com/pwr-Solaar/Solaar/blob/master/lib/logitech_receiver/hidpp20.py) 及其功能编号交叉核对。新增分支已做合成报文测试，尚未经过对应硬件验证；不代表已实测所有罗技型号。

## 逐设备设置

右键托盘图标 → 逐设备设置：修改别名、隐藏/恢复设备、设置独立低电量阈值或关闭单台设备提醒。隐藏设备仍可从此入口找回；设置按设备 ID 保存，不影响硬件识别。

蓝牙/HID 现在独立查询；慢通道显示缓存，正常通道继续更新。失败后自动延长重试间隔（最长 5 分钟），手动刷新、设备插拔及系统唤醒可触发提前重试。同一通道正在查询或清理时不会重复发起。休眠状态模型已加入，但当前协议缺少可靠的休眠/关机区分证据时仍显示未知。

HID 无有效读数的退避按物理接收器保存，罗技配对设备进一步按槽位保存；正常设备仍按设置的间隔查询。连续失败采用刷新间隔的 2、4、8 倍等延迟，最长 5 分钟，成功后恢复正常；退避期间保留旧读数并标记连接未知。接收器从枚举中消失后清除对应退避记录，手动刷新与系统事件可提前重试。HID 访问仍为串行，首次慢查询及底层驱动阻塞尚未实现接收器间并行隔离；枚举失败或整个通道超时仍会触发通道级退避。

托盘颜色按各可见设备自己的低电量阈值判断：任一设备达到阈值即提示，达到阈值且不超过 10% 时显示红色，其余低电量显示橙色；缓存、休眠及充电中的读数不参与告警。托盘电池填充长度仍表示最低有效电量。关闭单台设备的通知只关闭弹窗，不关闭颜色提示。
