# 蓝牙缓存与错误提示验证

日期：2026-11-19。

- BLE 与经典蓝牙共用按设备 ID 区分的读数缓存，保存完整读数及原始时间。没有新电量时返回缓存，不重置 LastSeen；断开时重复的 Windows 属性值也不重置原时间。
- 经典蓝牙不再因为电量属性暂时缺失而丢弃有缓存的设备。单设备异常独立捕获，其他设备继续扫描；打开 BLE/经典蓝牙设备各有 5 秒取消超时。
- 单设备异常保留该设备缓存；通道枚举失败保留该通道缓存；BLE 时间预算耗尽明确提示并回退被跳过设备的缓存。
- 部分成功时仍传递蓝牙警告到最终快照。主窗口显示可点击的错误入口，点击对话框或悬停可读完整错误；成功扫描自动清除旧警告。
- Windows BatteryLife 属性是操作系统提供的读数，收到属性时的时间表示观察时间，不保证是硬件实际采样时间。应用自身的缓存回退始终标记为缓存。

验证：Framework 编译成功，69 项自检全部通过。新增 8 项检查缓存数值、原始时间、缓存状态、断开状态的重复属性、恢复、无历史读数、设备隔离与零电量、缓存释放。未进行真实 BLE/经典蓝牙故障注入或界面点击实测。
