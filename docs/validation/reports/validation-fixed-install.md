# 固定安装目录与诊断身份重构验收

日期：2026-11-20，版本 1.2.3.0。

## 目录与入口

- src/：源码；artifacts/build/：编译与无托盘诊断；dist/v1.2.3/：当前分发安装包。
- 固定运行文件：%LOCALAPPDATA%/Programs/WirelessBatteryMoniter/WirelessBatteryMoniterTray.exe。
- Start.cmd 安装/升级后启动；Install.cmd 只安装；run.ps1 启动固定目录中的已安装版。
- 开发与发布 EXE 正常启动在创建托盘前检查路径，不在固定路径则提示安装并退出。自检、扫描、UI/图标导出在路径限制之前处理。
- 旧版本、临时修复版和旧暂存备份共 11 个目录归档到 artifacts/archive/releases-before-fixed-install/；迁移清单 migration.json。没有删除历史材料。

## 安装与诊断

安装器复用发布事务脚本（打包为 install-transaction.ps1），核对全部 6 个安装文件的 SHA256；同目录暂存、备份、切换与异常回滚。相同文件重复安装不替换，禁止版本降级；需升级时要求先退出应用。文件安装完成后创建桌面快捷方式，迁移已有开机项，不为未开启的用户新增开机项。壳集成失败可重跑安装修复；文件事务不包含快捷方式和注册表，也不是断电原子事务。

移除随机 GUID 原生诊断实例，NativeTrayIcon 只保留静态文字更新结构。--diagnose-tray 改为离线位图导出，不向 Explorer 注册任何图标，报告明确不验证实时注册。

## 验证

- Framework 编译通过；94 项逻辑自检通过；离线托盘诊断退出码 0。
- 5 项安装测试：首次安装、幂等重装、同路径升级并保留旧目录、文件占用失败保持旧版本、禁止降级。
- 8 项发布事务回归通过，包括发布后校验失败回滚与并发发布锁。
- 暂存及发布目录全部 10 个文件 SHA256 与 zip 一致。
- 已实际安装至固定用户目录，安装 EXE 与发布 EXE 哈希相同，版本 1.2.3.0。
- 桌面快捷方式和已有开机项均指向固定文件；实际运行 PID 17812；日志确认 Medium 完整性及托盘位置获取成功。
- 运行中重复执行相同包的安装启动入口，保留原单实例 PID，没有启动第二个常驻程序。

## 历史缓存处理

只读检查了 Windows 10 TrayNotify 项，历史记录存于共享 IconStreams/PastIconsStream 二进制值，不能按应用名直接删子键。本次未清空缓存、未重启 Explorer，避免影响其他应用的显示偏好。旧开关可能仍存在；本次消除新增的诊断随机身份及正常使用时的路径变化来源。无法保证 Windows 不因用户运行历史旧版、系统重建缓存等行为产生新历史记录。

SDK 编译路径未验证；实际托盘运行只验证当前 Windows 10。Windows 11 和其他设备组合不在本次覆盖范围。
