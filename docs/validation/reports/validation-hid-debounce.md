# 短暂 HID 通信失败防抖

日期：2026-11-19。

针对 2.4G/HID 设备，连续三轮完整扫描未读到才判定断开。前两轮保留原连接状态并标记缓存，界面显示连接待确认，LastSeen 不更新；成功读取重置该设备计数。取消扫描不进入 ApplyCache，因此不增加计数。计数逐设备隔离、忽略 ID 大小写并封顶，释放提供程序时清空。

缓冲期间不清除低电量提醒记录，也不使用缓存触发提醒；第三轮确认断开后，恢复连接可再次提醒。真实拔出设备也需要三轮完整扫描才显示断开，延迟取决于轮询间隔和扫描耗时。此改动不改变蓝牙提供程序。

验证：Framework 编译通过，61 项自检全部通过。新增 8 项覆盖第二次失败、短暂失败后恢复不重复提醒、恢复重置与大小写、第三次确认断开、时间戳、设备隔离、持续离线、确认断开后恢复提醒。未进行硬件通信抖动实测。

产物：dist/v1.2.1/WirelessBatteryMoniter.exe 和同目录 zip（v1.2.1 修订构建）。
