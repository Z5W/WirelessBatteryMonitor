# 发布暂存、回滚与完整哈希验证

日期：2026-11-19。仅修改构建与校验脚本，程序实现不变。

## 修改

- build.ps1 在唯一暂存目录生成文件和 zip，验证成功后交给 release-transaction.ps1 发布。
- 使用独占文件锁阻止同时发布；旧正式目录改名保留为 .previous-*，暂存改名为正式目录，再次执行验证。
- 切换或最终验证抛错时撤回新目录并恢复旧目录。失败暂存和成功发布的旧版本备份保留，回滚失败时明确输出恢复路径。
- verify-package.ps1 对所有归档文件计算 SHA256，对照发布目录逐一比较；重复条目（含大小写变体）、非白名单条目和路径穿越条目均失败。

故障夹具与各校验日志在 artifacts/tests/release-hash/，事务测试证据在 artifacts/tests/release-transaction-*/。测试夹具不可用于交付。

## 边界

两次目录改名不是断电级原子事务，强制结束进程、断电或存储故障可能需要手动恢复旧目录。自动回滚覆盖正常可捕获的异常，无法保证存储不可写时成功。未执行真实断电或占用中的程序强制升级测试。
