# 设置默认值与文档清理

日期：2026-11-19。

- 设置文件缺少字段时按文档默认值补齐：阈值 20%、刷新 10 秒、桌面提醒开启、提示音开启、显示未连接设备、启动最小化。此前 `DataContractJsonSerializer` 反序列化不执行构造函数，缺失字段会保留 CLR 默认的 0/false，实际表现为阈值被 `Normalize` 夹到 5%、刷新 5 秒、提醒关闭。
- 已有设置文件不会被当成首次运行，即使旧版本没有写入 `FirstRun`；文件里显式写入 `FirstRun=true` 仍会被尊重。
- 默认值通过 `[OnDeserializing]` 回调填充，再由文件中实际存在的成员覆盖，正常保存的完整文件行为不变；畸形 JSON 仍走原有的"备份并使用默认设置"路径。
- 删除 `docs/screenshot-tooltip.png`：自绘悬停卡片已在 1.2.1 移除，该截图会误导。
- `validation-timeout-results.md` 增加说明：HID 防抖后"成功返回空列表清除旧结果"只适用于蓝牙通道。
