# 柔和卡片界面验证（2026-11-20）

依据：`design/interface-design-plan.md` 最新版。使用 frontend-design skill，原生 WinForms 实现。

## 本次实现

- 默认浅色蓝主题，白色圆角卡片、状态胶囊、系统设备图标、32px 电量数字与较小百分号、8px 电量条。
- 默认客户区 520×720，最小客户区 420×560（逻辑像素）。宽度达到 800 时使用双列，窄窗口单列，头部及操作区固定。
- 名称最多两行；悬停和设备详情显示完整名称。设备详情支持鼠标、Enter/Space 和辅助功能默认操作，Esc 关闭，关闭后焦点返回卡片。
- 首次展示按低电量排序，刷新复用卡片保持位置，新设备追加，重新打开窗口重新排序。
- 待确认与确认连接数量分开；缓存及离线读数不会渲染成新鲜低电量警报；0% 不填充，未知值仅显示轨道和破折号。
- 设置按设备监控、低电量提醒、启动与后台分为圆角面板；说明文本按宽度测量并增高。底部操作固定。
- 按钮和卡片悬停反馈使用 140ms；详情 180ms 淡入，读取 Windows 客户区动画开关，禁用动画时即时呈现。键盘焦点使用主题色外框。
- 更新正在扫描时的按钮状态，扫描协议、防抖、缓存、通知触发规则和固定安装身份未改变。

首期交付浅色主题；深色主题切换未增加。Segoe UI 及 Windows 中文回退保持原规则，WinForms 与 Chromium 的实际回退渲染不能保证完全一致。本次没有读取或操控 Codex 窗口来进行逐字对比。
