# 扫描超时保留有效结果

日期：2026-11-19。

- 扫描服务管理 35 秒超时；调用方取消仅表示退出或主动取消，仍停止发布结果。
- 蓝牙和 HID 独立收集结果，成功通道正常更新。取消或异常通道保留上次成功结果并标记缓存，保留原始 LastSeen。
- 成功返回空列表会清除该通道的旧结果；恢复后自动清除异常提示。
- 主窗口显示失败通道和原因，缓存连接状态显示“连接待确认”。正常通道的新鲜低电量读数继续提醒，缓存读数不触发提醒。
- 为避免设备句柄释放或下轮扫描与未完成 I/O 竞争，仍等待两个通道完成取消清理；35 秒是取消请求时间，不是驱动卡死时的强制返回保证。

验证：Framework 编译通过；53 项自检全部通过。新增 9 项覆盖双向单通道超时、全通道超时、缓存时间、异常提示、恢复与清空、退出取消、单通道异常和部分成功时的低电量提醒。本次未进行硬件超时实测。

产物：dist/v1.2.1/WirelessBatteryMoniter.exe 与同目录 zip，本次作为 v1.2.1 修订构建。

> 后续修订（同日）：HID 通道加入三轮防抖后，成功扫描不再立即清除该通道的旧设备——前两轮保留连接状态并标记缓存，第三轮才标记未连接。因此上文"成功返回空列表会清除该通道的旧结果"仅适用于蓝牙通道，HID 行为见 [HID 防抖验证](validation-hid-debounce.md)。
