# 页面重写验证记录（2026-11-20）

依据：`design/interface-design-plan.md`；使用 frontend-design skill。范围为主窗口、设置、可复制的错误详情。关于页仍固定大小，仅同步字体、颜色和真实 DPI 缩放；提醒仅修正 DPI 坐标。设备协议、读取缓存和托盘身份保持原有实现。

## 实现

- 六个主色遵循方案，Segoe UI 常规/粗体，中文使用 Windows 字体回退。
- 主窗口初始 520×680 逻辑像素，可调整大小；顶部、底栏固定，列表独立滚动。
- 首次低电量优先，后续按设备 ID 复用行与位置；名称换行并可悬停查看全文。
- 状态、低电量、未知电量、缓存电量、最近成功读取时间独立呈现；底栏显示扫描结束时间。
- 设置三分组，滚动内容与固定保存栏分离；关闭通知禁用阈值、声音与测试，并说明原因。
- 详情窗口提供只读可选文本与复制；保存失败保留设置页。
- 保留关于、退出、关闭隐藏到托盘；修复后的单次鼠标点击行为未回退。
- Manifest 改为 System DPI aware，自绘元素按真实系统 DPI 绘制，避免整窗位图放大。不同 DPI 显示器之间移动仍按系统 DPI，需重启适配新的系统缩放。

## 复现

```powershell
.\build.ps1 -FrameworkCompiler -Package
.\tools\verify.ps1
.\tools\test-ui.ps1
```

页面测试不建立托盘图标、不保存用户设置。结果与截图位于 `artifacts/tests/ui-redesign/`，逻辑测试位于 `artifacts/tests/validation/`。

## 验证范围

- 94 项逻辑自检通过。
- 28 项页面检查通过：首次排序、刷新复用与稳定顺序、缓存时间、未知值、长名称、多同名设备、滚动、固定底栏、空状态、忙状态、窗口缩放、关闭隐藏、设置控件边界、通知联动、键盘箭头、左键单击、右键不激活、空格激活、错误文本及复制入口，以及三档模拟缩放的边界检查。
- 本机实际系统 DPI 为 125%，正式 EXE 导出的主页面、设置、关于页已目视检查；长名称、部分失败、错误详情也检查过。
- 100%、150%、200% 使用离屏测试同时缩放控件和字体，并设置行布局比例。它验证布局几何，不表示在这些真实 Windows DPI 或跨显示器切换下已经实测。
- 测试确认复制按钮入口与可选择文本；未覆盖真实剪贴板被其他应用锁定时的交互。代码提供重试反馈。
- 发布脚本继续校验全部 10 个发布文件的 SHA256。安装仍覆盖固定路径，不新增随机托盘身份。
