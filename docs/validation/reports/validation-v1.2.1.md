# v1.2.1 悬停提示验证

日期：2026-11-19。

## 修改

- 删除 TrayTooltipForm、自绘卡片触发逻辑、悬停定时器以及相关预览/导出入口。
- 第一行保留程序名称及已连接设备数量，删除最低电量。
- 设备行格式：`[2.4G] 鼠标: PRO X2 SUPERSTRIKE 70%电量`。
- 使用 Shell 原生提示 127 字符容量，绕开 .NET Framework NotifyIcon.Text 的 63 字符限制；保留程序名/数量作为异常时的回退文字。
- 名称缩略及超限数量提示；未知型号不猜测类型；缓存/未连接状态与设置一致。
- 图标刷新、重新注册、周期检查后重新写入完整提示文字。
- 临时原生诊断使用每次独立的 GUID，避免并排版本路径不同造成诊断图标身份冲突。

## 验证结果

- Framework 编译通过。
- 44 项自检全部通过，其中新增 6 项验证精确格式、最低电量移除、127 字符上限、超限提示、断连显示偏好及未知类型。
- 96 字符双设备提示通过 Shell_NotifyIcon 更新成功。
- WinForms 与原生 API 的静态、动态、重新注册共 6 项检查通过；重新写入长提示成功。
- 测试对象：`dist/v1.2.1/WirelessBatteryMoniter.exe`，自检与托盘诊断退出码均为 0。
- 未停止或替换用户正在运行的旧版；发布 exe 已设为中完整性。使用前需从主窗口或托盘菜单退出旧版。

本轮未模拟用户鼠标悬停截图；测试验证格式逻辑及 Windows API 接受长文本，真实视觉效果需要运行新版后悬停确认。系统字体、颜色不可逐行自定义；文字过多时完整列表在主窗口。
