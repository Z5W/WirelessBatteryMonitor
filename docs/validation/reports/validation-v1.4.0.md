# v1.4.0 发布验证

日期：2026-11-22。

## 范围

检查逐设备偏好、蓝牙/HID 独立通道调度、系统设备/电源事件、充电状态、电量来源与精度、未知连接状态及提醒处理。程序集、项目版本和用户说明统一为 1.4.0。

## 验证结果

- `build.ps1 -FrameworkCompiler -Package`：构建及打包通过，文件版本为 1.4.0.0。
- 对发布 EXE 执行 `tools/verify.ps1`：168 项逻辑检查通过，覆盖偏好保存、旧配置兼容、通道退避与超时隔离、充电/估算/未知状态和提醒行为。
- 在正常桌面会话对发布 EXE 执行 `tools/test-ui.ps1`：68 项界面检查通过；查看逐设备设置和估算读数截图，未发现新增裁切。
- `tools/test-release-transaction.ps1`：8 项检查通过，覆盖失败回滚、首次发布、旧版本保留及并发锁。
- `tools/test-install.ps1`：5 项检查通过，覆盖首次安装、重复安装、升级、锁定文件保护及降级拒绝。测试使用独立目录，不修改真实安装或开机项。
- 发布包包含 10 个白名单文件，EXE 为 Medium 完整性；ZIP 内每个文件的 SHA256 与发布目录一致。

## 限制

本次没有重新进行真实硬件扫描、充电状态实测、睡眠/唤醒循环或多显示器 DPI 验证。协议未确认的充电/休眠状态仍保持未知；真实 HID 拔出也可能持续显示连接未知。逻辑与离屏界面检查不能替代这些实测。

原始结果和截图保存在本地 `artifacts/tests/`，不随源码或安装包公开。
