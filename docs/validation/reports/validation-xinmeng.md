# XINMENG 3151:5045 兼容性修复

日期：2026-11-19；发布版本 1.2.2，包含此前界面文字清理。

根因：该鼠标接收器的电量接口为 UsagePage FFFF / Usage 0002，FeatureReportLength 65，OutputReportLength 0。旧筛选条件要求 OutputReportLength > 0 且只覆盖其他 UsagePage，因此它未进入扫描。

根据用户已安装 XINMENG Driver 3.2.7 的本地接收器状态查询逻辑，独立实现 F7 Feature Report 状态查询；仅匹配 3151:5045 和上述接口。报告 ID 为 0，65 字节原生缓冲含报告 ID；鼠标电量在索引 3，连接状态索引 5，配对设备类型索引 7，RF boot 标志索引 9。只接受含鼠标、在线且非 boot 状态，电量 0–100。

只发送 F7 状态查询，不发送 F6 设备选择、配对、配置或固件命令。不依赖用户驱动运行，也不分发第三方代码。未声称支持所有 XINMENG 型号。

验证：同一查询重复三次返回 98%；完整扫描同时返回三只设备，均非缓存：PRO X 2 55%、PRO X2 SUPERSTRIKE 67%、XINMENG 2.4G 鼠标 98%。84 项自检通过，新增 12 项覆盖 Feature-only 筛选、原始回包、0/100 边界、断开/休眠、boot、未配对鼠标、错误 ID 和长度等。

- 自检结果（本地归档，不公开）
- 三只鼠标扫描结果（本地归档，不公开）

状态查询未提供可靠营销型号，因此界面显示 XINMENG 2.4G 鼠标。身份仍按接收器物理路径区分，沿用 HID 三轮防抖与缓存。尚未验证真实断连/重连、长期与官方驱动并发使用；Feature API 是同步调用，驱动卡住时仍不能保证立即取消。
